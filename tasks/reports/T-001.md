**Why nothing links:** the machine has only an empty "Visual Studio Build Tools 2019" shell
(`isComplete: false`; `VC\Tools\MSVC\14.29.30133` has no `link.exe` or CRT libs, and
`C:\Program Files (x86)\Windows Kits\10` has no `Lib`). The only `link.exe` on `PATH` is Git's
coreutils `link`, which rustc invoked and which failed with `extra operand`. Fix: install the
"Desktop development with C++" workload (MSVC v14x + Windows 10/11 SDK) and rerun the commands above.
I did not do this myself: it is a multi-GB, admin-level system install.

**Unverified code:** `crates/inklore-cli/src/main.rs` and `tests/cli.rs` have never been compiled. The
`--version` output (`inklore 0.0.0`) and the one-line `--help` description rely on clap's documented
behaviour; they must be confirmed by running the commands once a linker exists.
